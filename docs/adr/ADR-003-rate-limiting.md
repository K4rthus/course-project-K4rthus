# ADR-003: Rate Limiting для защиты от DoS и брутфорс атак

Дата: 2025-03-11
Статус: Accepted

## Context
Анализ рисков выявил критические угрозы:
- **R1**: Брутфорс атаки на аутентификацию (F1) - вероятность 4, влияние 3
- **R4**: DoS через создание предложений (F3) - вероятность 3, влияние 4  
- **R9**: DoS атака на базу данных - вероятность 2, влияние 5

NFR-03 требует защиты от brute-force, NFR-01 - обеспечения производительности под нагрузкой.

## Decision
Внедряем многоуровневый rate limiting на основе Redis для горизонтального масштабирования:

1. **Эндпоинт-specific лимиты**:
   - `POST /suggestions`: 10 запросов/минуту на user-id (mitigates R4)
   - `POST /login`: 5 попыток/минуту на IP (mitigates R1, соответствует NFR-03)
   - `GET /suggestions`: 60 запросов/минуту на IP
   - Глобальный: 1000 запросов/час на IP

2. **Техническая реализация**: Redis + sliding window algorithm
3. **Ответы**: 429 Too Many Requests с Retry-After header

## Alternatives
1. **Token bucket algorithm** - более равномерное распределение, но сложнее реализации
2. **Fixed window** - проще, но подвержен всплескам в конце окна
3. **Встроенный в nginx** - быстрее, но менее гибкие правила

Выбран sliding window как оптимальный баланс точности и сложности.

## Consequences
**Плюсы:**
- Mitigates R1 (снижение с 12 до 4), R4 (снижение с 12 до 4)
- Соответствует NFR-03, NFR-01, NFR-08
- Защита БД от перегрузки (R9)

**Минусы:**
- Зависимость от Redis (дополнительная точка отказа)
- +5ms на проверку лимитов при p95

## Security Impact
**Влияние на безопасность:**
- Снижение риска DoS атак через исчерпание ресурсов
- Защита от credential stuffing атак
- Соответствие SLO 99.5% доступности (NFR-02)

**Мониторинг:**
- Метрики блокировок по эндпоинтам и IP
- Алерты на аномальные паттерны запросов

## Rollout Plan
1. **Фаза 1**: Развернуть Redis cluster в production
2. **Фаза 2**: Включить rate limiting с либеральными лимитами (2x от планируемых)
3. **Фаза 3**: Мониторинг в течение 7 дней, настройка лимитов под нагрузку
4. **Фаза 4**: Постепенное ужесточение лимитов до целевых значений

**DoD:**
- [ ] Redis cluster развернут и мониторится
- [ ] Rate limiting работает на всех эндпоинтах
- [ ] Логи блокировок содержат correlation_id
- [ ] Нагрузочные тесты показывают p95 < 200ms под лимитами
